## 概要
本リポジトリは、React を用いて開発した
Twitter クローンアプリのフロントエンドです。

Rails API サーバーと連携し、
モダンな SPA（Single Page Application）として設計・実装しており、
認証・投稿・通知など、SNS に必要な主要機能を網羅しています。

## 使用技術
- React 19.1.1
- Axios
- Tailwind CSS 4.1.16

## 機能一覧
- サインアップ・ログイン(devise_token_auth)
- プロフィール閲覧・編集
- ツイート機能(テキスト&画像)
- いいね
- リツイート
- フォロー
- コメント
- ブックマーク
- メッセージ機能(DM)
- 通知機能
- 退会機能

## 工夫した点
- バックエンド（Rails API）と完全分離したフロントエンド専用構成で設計
- コンポーネントの責務を明確にし、再利用可能なコンポーネント設計を意識
- Axios を用いて API 通信処理を共通化し、ヘッダー設定を一元管理
- 認証情報（トークン）を適切に管理し、ログイン状態を維持できる設計
- SPA（Single Page Application）として、ページ遷移時のユーザー体験を最適化
- Tailwind CSS を用いて ユーティリティファーストなスタイリング設計を採用
- UI コンポーネントを分割し、再利用性と保守性を向上
- 投稿・コメントなどの入力フォームを共通コンポーネント化し、再利用性を向上
- 画像付きツイートに対応し、テキスト投稿との共存が可能な設計
